# Отчёт по лабораторной №3

## Источник
Выбран официальный XML BNM: открытый источник без ключа, содержит MDL и исторические даты. Номинал нормализуется Value/Nominal, расчёт выполняется через Decimal. Проверены реальные ответы за текущую и прошлые даты. Доступность внешнего сервиса не гарантирована, поэтому есть кэш и сообщения об ошибках.

## Инструменты и модели
Настоящий Spec Kit 1.2.4 инициализирован с интеграцией Codex. Требования, план, задачи и проверка согласованности сохранены в отдельном PR до исходников приложения. Все спецификации, код и проверки подготовлены Codex в этой сессии. Точное имя модели не фиксировалось.
Copilot и Antigravity не использовались по явному решению пользователя от 28.10.2026. Моделей Antigravity в этой работе нет. Это отличие от процесса методички.

## Что получилось с первой попытки
Разбор реального XML и получение 41 валюты с учётом MDL. В интерфейсе проверено 100 EUR → 2017,60 MDL по официальному курсу на 28.10.2026. Отрицательный ввод отключает кнопку.

## Ошибки и исправления
При разделении Docker на стадии app/tests первоначальная последовательность требовала файлов будущей тестовой ветки даже для app при классическом сборщике. Стадия приложения перенесена перед стадией тестов.
Пользователь вручную исходники не правил; исправления выполнены Codex. Отчёт не приписывает пользователю или Antigravity несуществующие действия.

## Соответствие спецификации
Реализованы веб-интерфейс, проверка ввода, дата/источник, одинаковые валюты, расчёт в обе стороны, поиск предыдущего доступного дня и постоянный кэш с явным выбором. В отдельной тестовой ветке проходят 30 проверок XML, номинала, расчёта, дат, пустых/некорректных ответов, HTTP и кэша.
Дополнительно новый контейнер с отключённой сетью прочитал настоящий сохранённый курс на 28.10.2026 и рассчитал 100 EUR → 2017,60 MDL. Это проверяет сохранность данных за пределами процесса и контейнера.
Работа на Windows-ноутбуке остаётся ручным этапом. Образы linux/amd64 подходят для выбранной Windows 11 AMD с Docker Desktop, но реальная проверка там ещё не выполнена.
